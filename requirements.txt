# IngeTrazo runtime + dev dependencies.
#
# Deliberately minimal: the engine runs on PySide6 alone (Qt's bundled OpenGL
# for rendering, QtGui's QMatrix4x4/QVector3D for math, the stdlib `array` for
# vertex packing). NumPy joined in the georef DEM work (Track G, G2) for
# heightfield decode/sampling. No native mesh/BIM libraries yet — those are
# added only when the feature that needs them actually lands.
