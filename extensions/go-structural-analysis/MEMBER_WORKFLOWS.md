# ASD/LRFD และกราฟสมาชิก — v0.2.4

## Load Combinations

เลือก **ASD + LRFD** เพื่อเลือกสูตรทั้งสองวิธีในโมเดลเดียวกัน หรือเลือก ASD
ก่อนแล้วเปลี่ยนไป LRFD เพื่อเพิ่มสูตรได้ ชุดเดิมคงอยู่ และเพิ่ม Custom ได้ใน
หน้า Combinations เช่นเดิม Generator เพิ่มสูตรของวิธีที่เลือกและเก็บอีกวิธีไว้
หากต้องการปิดสูตร ให้เปลี่ยนไปวิธีนั้นและเอาเครื่องหมายเลือกออก

ผลและ Envelope ยังคงแยกกลุ่ม ASD / LRFD / Custom เพื่อระบุวิธีออกแบบชัดเจน
Action bindings ใช้ร่วมกันทั้งสองวิธี เมื่อแก้ Inputs ต้อง Run Analysis ใหม่
ยังไม่มีการตรวจ Capacity / Code Compliance

## แรงกระจาย

เลือกแถว Distributed Loads และระบุ Member ระบบแสดง **L [m]** จากพิกัดจริง
x1/x2 วัดจากปลาย i ไป j กด **Full member** เพื่อใส่ x1=0 และ x2=L
โหลดบางช่วงยังกรอกระยะเองได้ ความยาวที่แสดงรวมพิกัด XYZ ของคานเอียงด้วย
การแก้พิกัดจะอัปเดตข้อความความยาว แต่ไม่แก้ช่วงโหลดที่กรอกไว้เอง

## หน้าต่างกราฟ

Run Analysis ให้ผลเป็น Current แล้วคลิกขวา Member → **Member Graphs / กราฟสมาชิก**
เลือก Selected member หรือ Connected collinear เพื่อแสดงสมาชิกที่ต่อด้วย Node
เดียวกันและอยู่แนวเดียวกัน เลือก Case/Combination, N/V/M/D ใน 2D หรือ
N/Vy/Vz/T/My/Mz/D ใน 3D และอ่านค่าที่ x/L พร้อมเลือกด้านซ้าย/ขวาของจุดแรง

โหมด Connected collinear แสดงกราฟเดียวบนแกนระยะสะสม เช่น 4+4 เมตรเป็น
0–8 เมตร ใช้สเกลเดียวกัน มีชื่อ Member, Node และระยะที่จุดต่อ คานหลายช่วง
เลื่อนตามแนวนอนได้ คลิกบนกราฟเพื่ออ่านค่าที่ตำแหน่งนั้น หรือเลือก Member/x/L
เพื่ออ่านตำแหน่งในสมาชิก พร้อมแสดงระยะสะสม s

กราฟกลุ่มใช้แกนอ้างอิงของสมาชิกที่คลิกขวา สมาชิกกลับทิศและหน้าตัดหมุนจะถูก
แปลงแรงหน้าตัด/การโก่งตัวเข้ามาสู่แกนเดียวกันก่อนแสดง เครื่องหมายและผลดิบ
ของ Solver คงเดิม Min/Max ค้นจาก Polynomial ที่แปลงแล้ว ไม่ใช่ Sampling
ค่ากระโดดที่แรงจุด โมเมนต์จุด จุดต่อกับเสา หรือ Release ยังคงแสดงตามผลจริง
ตัวเลือก left/right ในกราฟกลุ่มหมายถึงด้านตามแกนระยะสะสม

กรณีสมาชิกซ้อนทับหรือแตกแขนงจนเรียงเป็นคานเส้นเดียวไม่ได้ ระบบแสดงเหตุผล
ให้ตรวจ Model ก่อน และไม่สร้างกราฟต่อเนื่องที่ผิดจากการเชื่อมต่อจริง
กราฟพื้นที่บวกสีน้ำเงิน ลบสีส้ม พร้อมเครื่องหมายตัวเลข เมื่อผล Stale กราฟจะถูก
ปิดและแสดง RESULTS OUT OF DATE
